GitHub Pages + YouTube Data API

Artiesten naar YouTube-playlist

Zoekt populaire muziekvideo’s, ook op labelkanalen, en maakt een playlist in jouw YouTube-account.

1. Google-configuratie

Deze waarden blijven uitsluitend in localStorage van deze browser. Beperk je API key in Google Cloud tot YouTube Data API v3 en jouw GitHub Pages-domein.

2. Playlist

De app zoekt over heel YouTube, dus ook op labelkanalen. Selectie gebeurt op artiestnaam, videotype, uitsluitwoorden en views. Dit blijft een heuristische benadering: YouTube markeert niet betrouwbaar elke officiële muziekvideo.
